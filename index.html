Security model

Strong cloud architecture without trusting the browser.

What the app does

  • Uses HttpOnly secure cookies for authenticated sessions.
  • Stores only server-side hashed credentials.
  • Validates file access and permissions on the backend.
  • Separates private, shared, and community areas.

Operational requirement

  • Cloudflare D1 stores metadata and access records.
  • Cloudflare R2 stores encrypted private objects without public access.
  • Cloudflare Workers enforce auth, rate limits, and policy checks.
  • Browser-side encryption protects user files before upload.
